# Mi App Personal

App personal de productividad, salud, finanzas y negocios.

## Módulos
- ✅ Tareas con score diario
- 💰 Finanzas (ingresos, gastos, deudas, suscripciones)
- ❤️ Salud (contadores, hábitos, medicamentos, peso)
- 📸 Contenido (agenda semanal, ideas)
- 🏢 Negocios (empresas, categorías, tareas)
- 📅 Eventos y recordatorios
- 👤 Perfil y gamificación

## Stack
- HTML + CSS + JavaScript vanilla
- PWA (instalable)
- localStorage para persistencia
